How it works

  1. Text Cleaning – lowercase, HTML strip, punctuation removal, stop-word filtering
  2. TF-IDF Vectorization – unigrams + bigrams, 50,000 features, sublinear TF scaling
  3. Logistic Regression – L2 regularisation (C=1.0), lbfgs solver
  4. Output – predicted class (positive / negative) + probability scores
